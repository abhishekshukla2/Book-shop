# 📚 Book Shop Website

A simple and responsive **Book Shop Frontend Website** created using **HTML and CSS**. This project focuses on creating a clean, attractive, and user-friendly interface for an online book store.

## ✨ Features

* 🏠 Responsive Home Page
* 📚 Book Collection Section
* 🛍️ Attractive Book Cards
* 🔍 Search UI
* 📖 Book Information
* 📱 Mobile Responsive Design
* 🎨 Clean and Modern UI
* 📞 Contact Section
* 🧭 Easy Navigation

* CSS3

## 💻 How to Run

1. Clone the repository:

```bash
git clone https://github.com/abhishekshukla2/Book-shop.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
